# **THE IZEN MANIFESTO**

### Unified Architecture Principles

1. **Truth resides in the workspace.**
   The source of truth is the actual code and artifacts on disk—not an LLM's assumptions.

2. **Knowledge is resolved, not assumed.**
   Every piece of knowledge must be resolved through a defined precedence hierarchy, never guessed.

3. **Context is governed, not accumulated.**
   Context is a managed resource controlled by policy, not an ever-growing collection of information.

4. **Execution is orchestrated by the runtime, not by agents.**
   Execution flow is deterministically coordinated by the runtime, independent of conversations between agents.

5. **Validation is policy-driven, not hardcoded.**
   Verification and testing are governed by workspace-specific policies rather than fixed implementation logic.

6. **LLMs generate changes—they never own the system state.**
   LLMs may propose modifications, but they never become the authoritative owner of the system's state.
